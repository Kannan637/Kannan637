# 💫 About Me

🤖 **AI Automation Engineer** building agentic systems that turn manual business workflows into autonomous, self-running pipelines.

🧠 **AI Prompt Engineer** — I design, test, and optimize prompts and multi-agent orchestration (LangGraph, CrewAI) for reliable, production-grade LLM behavior.

🎨 **AI Creative** — I bring the same AI toolkit into branding, motion graphics, and content design through my studio, **letsbeigin.studio**.

🚀 Currently building **Recart**, a WhatsApp cart-recovery automation SaaS for Indian D2C/Shopify merchants — powered by agentic AI, Groq, and the Meta WhatsApp Cloud API.

💼 Freelance AI Engineer & Full-Stack Developer delivering automation-first SaaS and enterprise AI solutions for global clients.

🌱 Currently exploring:
- Multi-agent orchestration (LangGraph, CrewAI)
- Retrieval-Augmented Generation (RAG) pipelines
- Workflow automation (Celery, Redis, n8n-style pipelines)
- Advanced prompt engineering & evaluation
